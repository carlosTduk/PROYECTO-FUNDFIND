# 💚 FundFind

> **Conectando donantes con fundaciones verificadas y solicitudes reales de ayuda.**

**FundFind** es una aplicación móvil desarrollada en el marco del **Proyecto de Internacionalización UNIVA – Universidad de Cundinamarca**. Su objetivo es centralizar y transparentar los procesos de donación, permitiendo a los usuarios explorar fundaciones verificadas y responder a solicitudes activas de manera rápida y segura.

---

## 🚀 Funcionalidades principales

* **Exploración y búsqueda inteligente:** Buscador de fundaciones y solicitudes activas con filtros por categoría (infancia, animales, medicamentos, etc.) y ubicación.
* **Tablero de métricas en tiempo real:** Visualización rápida de solicitudes activas y fundaciones verificadas.
* **Gestión de solicitudes recientes:** Detalle completo de cada necesidad (fundación responsable, categoría, ubicación, fecha límite y acceso directo para donar).
* **Fundaciones destacadas:** Directorio de organizaciones verificadas para conocer su labor y apoyarlas directamente.
* **Sistema de favoritos y avisos:** Guardado de causas de interés y notificaciones sobre actualizaciones o nuevas solicitudes.
* **Modo Invitado y Perfil de Donante:** Posibilidad de explorar la plataforma como invitado o gestionar un perfil personalizado.

## 🛠️ Metodología y Organización

El proyecto se gestiona bajo un enfoque ágil híbrido para asegurar entregas continuas y visibilidad del avance:
